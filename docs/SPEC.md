# Product spec: Read AI

The spec lives in `Product materials/`. This file only points to the right document.

| Question                                                         | Document                                            |
| ---------------------------------------------------------------- | --------------------------------------------------- |
| What and why: requirements BR-xx, rules, use cases, restrictions | `Product materials/business-requirements.md` (BRD)  |
| How: architecture, TR-xx, data design, story texts               | `Product materials/technical-requirements.md` (TRD) |
| Developer reference: metrics, mismatch rules, routes, env        | `Product materials/product-documentation.md`        |
| What the user sees                                               | `Product materials/app-walkthrough.md`              |
| Tasks, acceptance criteria, error codes, Definition of Done      | `Product materials/task-breakdown.md`               |

When documents conflict, the BRD and TRD win over the older ReadAssist documents (`PRD.md`, `TRD.md`,
wireframes, `HiFi-Design.md`).
